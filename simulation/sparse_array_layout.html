ผังการวางตำแหน่ง Transducer + Sparse Receiver Array แบบ L-shape (มองจากด้านบน)

แผนผังนี้วาดตามมาตราส่วนจริง (มิลลิเมตร) ให้คุณใช้ไม้บรรทัดวัดแล้ววางลงบนกระดาษ/โต๊ะได้เลย ตัวรับกระจายอยู่ 2 แขนตั้งฉากกัน (แกน X และแกน Y) บนระนาบโต๊ะแบนๆ — ไม่ใช่เส้นตรงเดียวซ้าย-ขวา เหมือนก่อนหน้า เพื่อให้ทำ multilateration เต็มรูปแบบ ได้ (หาทั้งมุมและระยะพร้อมกันจากหลายจุดวัด โดยตรง ไม่ต้องพึ่งการประมาณระยะแบบ monostatic จากช่องเดียว) แต่ละแขนยังคงใช้ระยะห่างแบบ ไม่เท่ากัน (sparse) เหมือนเดิม และจงใจใช้ชุดตัวเลขคนละชุดกันระหว่างสองแขน เพื่อไม่ให้เกิดความกำกวม ซ้ำกันโดยบังเอิญระหว่างแขน

ระยะห่างระหว่างตัวรับ (ต้องไม่เท่ากัน)

แขนคู่ระยะห่าง (mm)
ทำไมต้องเป็นค่าพวกนี้: แขน X ใช้ชุด 8,13,21,34mm ส่วนแขน Y ใช้ชุด 11,18,29mm (คนละชุดกัน โดยตั้งใจ) ทำให้ผลต่างระหว่างตัวรับแต่ละคู่ในภาพรวมซ้ำกันน้อยที่สุด — ถ้าใช้ระยะเท่ากันหมดทุกคู่/ทุกแขน จะเกิด grating lobe ซ้ำที่มุมเดียวกันทุกคู่ ทำให้แก้ความกำกวมไม่ได้เลยแม้จะมีตัวรับเยอะแค่ไหนก็ตาม

Legend

T = ตัวส่งคลื่น (transmitter) — อยู่ที่มุมของตัว L
R1-R4 = ตัวรับแขน X (แนวนอน) — sparse spacing
R6-R8 = ตัวรับแขน Y (แนวตั้ง) — sparse spacing คนละชุดกับแขน X
โซนสีชมพู = พื้นที่ที่ควรเลื่อนวัตถุเป้าหมายไปเรื่อยๆ ระหว่างเก็บข้อมูล (มุมตรงข้ามตัว L พอดี ไม่บังแขนไหนเลย)
จุดขาว = ตำแหน่งวัตถุ + ArUco/สติกเกอร์สีเด่น ให้กล้องแกะรอย

มุมมองด้านข้าง (Side view) — ความสูงกล้อง

กล้องต้องมองตั้งฉากลงมาตรงๆ (มุม 90° กับโต๊ะ) จากขาตั้งเหนือกึ่งกลางกระดาษพอดี — เอียงแม้เล็กน้อย จะทำให้พิกัดที่แปลงจาก pixel ผิดเพี้ยน (perspective distortion) ความสูงประมาณ 50-70cm เหนือโต๊ะ ก็เพียงพอให้เห็นกระดาษทั้งแผ่นสำหรับพื้นที่ทำงานขนาดนี้ (ปรับตามมุมรับภาพจริงของกล้อง/เลนส์ที่ใช้) ต้องมี marker อย่างน้อย 4 จุดที่รู้พิกัดจริงแน่นอน (เช่น 4 มุมกระดาษ) เพื่อคำนวณ homography (pixel → mm)
