มองแผง face-on (เหมือนยืนหันหน้าเข้าหาแผง เซนเซอร์ทุกตัวพุ่งเข้าหาเรา) — ตำแหน่งของเซนเซอร์บนระนาบ หน้าแผง (แกน X = ซ้าย-ขวา, แกน Y = บน-ล่าง) เป็นตัวกำหนดความละเอียดเชิงมุมของภาพที่ได้ (azimuth จากการกระจาย แกน X, elevation จากการกระจายแกน Y) วงกลมโปร่งรอบแต่ละจุดคือขนาดตัวถังจริง 16mm (แสดงว่าไม่ชนกัน) ทุกหน่วยเป็นมิลลิเมตร origin = TX ที่จุดกึ่งกลางแผง

Difference Co-array (ทฤษฎีรองรับ)

แต่ละจุดคือ เวกเตอร์ผลต่างตำแหน่งของตัวรับทุกคู่ (pj − pi) — นี่คือ "ความถี่เชิงพื้นที่" (spatial frequency) ที่ array นี้วัดได้ ยิ่งกลุ่มจุดนี้กว้างและกระจายทั่ว 2 มิติ = ยิ่งแยกทิศทางได้ละเอียด ทั้งแนว azimuth และ elevation รูปตัว Y ทำให้ co-array กระจายรอบทิศเท่าๆ กัน (คล้ายกล้องโทรทรรศน์วิทยุ VLA)

ทฤษฎีที่รองรับการวางแบบนี้

1. Aperture & Angular Resolution (ความกว้าง array → ความละเอียดเชิงมุม)

ความละเอียดเชิงมุมของ array แปรผกผันกับความกว้างของ array เทียบกับความยาวคลื่น: θres ≈ λ/D (D = ความกว้าง aperture) ที่ 40kHz, λ≈8.6mm ถ้า D=160mm จะได้ θres ≈ 3° — ยิ่ง array กว้าง ยิ่งแยก ทิศทางละเอียด นี่คือเหตุผลที่ใช้ baseline ใหญ่ (4-8cm) ไม่ใช่ ≤λ/2 การใช้ระยะเล็กจิ๋ว (4.3mm) จะได้ aperture แคบมาก แยกทิศแทบไม่ได้เลย

2. Grating Lobe / Spatial Aliasing (ราคาที่ต้องจ่ายเมื่อใช้ baseline ใหญ่)

เพราะระยะห่าง element (16mm+) > λ/2 จึงเกิด grating lobe — มีทิศทางหลอกที่ให้สัญญาณแรงเท่ากับทิศจริง (spatial aliasing เหมือน undersampling ในสัญญาณเวลา) นี่คือ trade-off โดยตรงกับข้อ 1: baseline ใหญ่ = แยกมุม ละเอียด แต่มี ambiguity ต้องแก้ด้วยข้อ 3-4

3. Difference Co-array & Non-redundant Placement (หัวใจของ sparse array)

สิ่งที่กำหนดความสามารถของ array ไม่ใช่จำนวน element ตรงๆ แต่คือ เซตของผลต่างตำแหน่งทุกคู่ (co-array) วางแบบไม่สม่ำเสมอ (non-redundant) ทำให้ผลต่างแต่ละคู่ไม่ซ้ำกัน → co-array ยาว/กว้างขึ้นโดยใช้ element น้อย (ทฤษฎี Minimum Redundancy Array, Coprime Array) และเพราะ grating lobe ของแต่ละคู่อยู่คนละมุม เป้าหมายจริง จึงเป็นทิศเดียวที่ทุกคู่เห็นตรงกันพร้อมกัน — ช่วยแก้ ambiguity จากข้อ 2

4. Y-array / Uniform Angular Sampling (ทำไมเป็นตัว Y ไม่ใช่เส้นตรงหรือกากบาท)

แขน 3 อันมุม 120° ให้ co-array กระจายสมมาตรรอบทิศ ทำให้แยกทิศได้สม่ำเสมอทุกทิศทาง (ต่างจากเส้นตรงที่แยก ได้แค่แกนเดียว หรือกากบาทที่ sampling ไม่สม่ำเสมอในแนวเฉียง) — เป็นหลักการเดียวกับ กล้องโทรทรรศน์วิทยุ VLA ที่ใช้ผัง Y จริง การมีทั้งแกน X และ Y ยังให้ทั้ง azimuth และ elevation (depth/ทิศทาง 2 มิติ) ตามที่คุณต้องการ

5. TDOA / Multilateration (แปลงเวลา → ตำแหน่ง)

ตัวรับแต่ละคู่ที่ได้ผลต่างเวลา (Δt) นิยามเส้นโค้ง hyperbola หนึ่งเส้นที่เป้าหมายต้องอยู่ ตัวรับหลายคู่ที่ไม่อยู่ แนวเดียวกัน (ได้จากผัง 2 มิติ) → เส้น hyperbola หลายเส้นตัดกันที่จุดเดียว = ตำแหน่งเป้าหมายไม่กำกวม (หลักการ เดียวกับ GPS) นี่คือเหตุผลที่ต้องกระจายตัวรับทั้ง X และ Y ไม่ใช่เส้นตรงเดียว

6. Neural Network + Camera Ground Truth (แก้ส่วนที่สูตรตรงๆ แก้ไม่หมด)

grating lobe และ multipath ที่เหลือหลังข้อ 3-5 ยากจะแก้ด้วยสูตร delay-and-sum ตรงๆ NN ที่เทรนด้วยข้อมูลจริง (raw echo หลายช่อง + depth จากกล้อง Orbbec เป็น label) เรียนรู้ mapping ที่ซับซ้อนกว่าได้ — นี่คือ "learned beamforming / deep DOA estimation" ที่เป็นแกนของโปรเจกต์
