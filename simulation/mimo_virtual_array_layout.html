MIMO Virtual Array — 3 TX (coded, ยิงพร้อมกัน) + 4 RX

ผังนี้ใช้มาตราส่วนเดียวกับผัง Y-array ก่อนหน้า เพื่อเทียบกันตรงๆ — ของจริงมีแค่ 7 ตัว เท่าเดิม (3 TX + 4 RX แทนที่จะเป็น 1 TX + 6 RX) แต่เพราะ TX แต่ละตัวยิง code ต่างกัน (แยกด้วย matched filter ฝั่งรับ) ตัวรับ แต่ละตัวจึงแยกได้ว่าเสียงที่ได้ยินมาจาก TX ตัวไหน — เท่ากับมี "เส้นทาง TX→เป้าหมาย→RX" ที่แยกกันได้ถึง 3×4 = 12 เส้นทาง จากอุปกรณ์จริงแค่ 7 ตัว นี่คือที่มาของ virtual array ด้านล่าง

TX1-TX3 = ตัวส่ง 3 ตัว ยิงพร้อมกันด้วย code ต่างกัน
RX1-RX4 = ตัวรับ 4 ตัว แยกสัญญาณแต่ละ TX ด้วย matched filter
จุดชมพู = virtual element (ตำแหน่ง TXi + RXj)

Virtual (Synthesized) Array — Sum Co-array = TXi + RXj

แต่ละจุดชมพู = ตำแหน่งเสมือนของ element หนึ่งตัว คำนวณจาก virtual(i,j) = TXi + RXj (ผลบวกเวกเตอร์ตำแหน่ง) — เพราะ TX ห่างกันเป็นจำนวนเท่าของระยะ RX พอดี (design แบบ coprime/sparse MIMO) จุดทั้ง 12 จุดจึงเรียงเป็นตารางสม่ำเสมอสมบูรณ์ ไม่มีช่องว่าง ไม่ซ้ำตำแหน่งกันเลย — ได้ aperture เสมือน กว้างกว่าของจริงมาก จากอุปกรณ์จำนวนเท่าเดิม
