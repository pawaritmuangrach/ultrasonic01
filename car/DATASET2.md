# ชุดข้อมูลรอบสอง — อาเรย์สี่เหลี่ยม เก็บท่าทางด้วย

## ต่างจากรอบแรกตรงไหน

| | รอบแรก | รอบนี้ |
|---|---|---|
| ตำแหน่ง RX | เรียงเป็นเส้นนอน | **สี่เหลี่ยม (มุมของ plate_mini)** |
| ทิศที่รู้ได้ | ซ้าย-ขวาเท่านั้น | **ซ้าย-ขวา และ บน-ล่าง** |
| ท่าทางในข้อมูล | แทบไม่เปลี่ยน | **เปลี่ยน 8 ท่าอย่างเป็นระบบ** |

## ทำไมรอบแรกเรียนรูปร่างไม่ได้

วัดแล้วพบว่าโมเดลรอบแรก **อยู่ใต้เพดาน "รู้แค่ตำแหน่ง" ทั้งสองแกน**
(แนวนอน R2 0.534 เทียบเพดาน 0.809 · แนวตั้ง 0.670 เทียบ 0.728)

สาเหตุไม่ใช่โมเดล แต่เป็นข้อมูล: **ท่าทางแทบไม่เคยเปลี่ยนขณะที่ตำแหน่งคงที่**
พอตำแหน่งอธิบายภาพได้เกือบหมด โมเดลก็ไม่มีเหตุผลต้องเรียนอย่างอื่น

รอบนี้จึงบังคับให้สองอย่างนี้แยกกัน:
* **ท่าเปลี่ยน ตำแหน่งคงที่** — ยืนที่เดิม วน 8 ท่า
* **ตำแหน่งเปลี่ยน ท่าเดิม** — ท่าชุดเดียวกันทุกช่วง แต่คนละที่

## เพดานจริงของฮาร์ดแวร์

เบสไลน์ 110 มม. ที่ 40 kHz (คลื่นยาว 8.6 มม.) แยกแยะได้ **4.5 องศาทั้งสองแกน**

ที่ตาราง 80x60 หนึ่งช่องกว้าง 0.73 องศา แปลว่า **ความเบลอกินราว 6 ช่อง**
ตารางละเอียดขึ้นทำให้ภาพเนียนขึ้น ไม่ได้ทำให้เห็นละเอียดขึ้น

**แต่เป้าหมายยังทำได้** เพราะกางแขนเปลี่ยนความกว้างเงา 40-60 องศา
และย่อตัวเปลี่ยนความสูงมาก — ทั้งคู่ใหญ่กว่าขีดจำกัดสิบเท่า

## วิธีเก็บ

รันสองหน้าต่างพร้อมกัน อัดก่อน แล้วค่อยเริ่มตัวบอกท่า

```bash
# หน้าต่าง 1 — อัด (เปลี่ยน --start ตามช่วง)
python car/record.py --port COM5 --pins 35,34,32,33 --name pose --sections 1 --start 1 --minutes 3.5

# หน้าต่าง 2 — ตัวบอกท่า
python car/pose_cue.py --section 1
```

**ลำดับ `--pins 35,34,32,33` ต้องเหมือนกันทุกช่วง** เพราะเฟิร์มแวร์สุ่มทีละช่อง
เหลื่อมกัน 1.25 ไมโครวินาที ถ้าสลับลำดับ ความเหลื่อมจะเปลี่ยนไปด้วย
โมเดลเรียนความเหลื่อมคงที่ได้ แต่เรียนความเหลื่อมที่เปลี่ยนไปมาไม่ได้

### ห้าช่วง ตำแหน่งต่างกัน ท่าชุดเดียวกัน

| ช่วง | ยืนตรงไหน |
|---|---|
| 1 | กลาง 100 ซม. |
| 2 | กลาง 70 ซม. |
| 3 | กลาง 140 ซม. |
| 4 | เยื้องซ้าย 100 ซม. |
| 5 | เยื้องขวา 100 ซม. |

### แปดท่า วนสี่รอบ ท่าละ 6 วินาที

`ARMS DOWN · ARMS OUT (T) · ARMS UP · ONE ARM UP ·
HALF CROUCH · FULL CROUCH · BEND FORWARD · TURN SIDEWAYS`

= 3.2 นาทีต่อช่วง · ห้าช่วงราว 18 นาที · ได้ราว 14,000 เฟรม

### แล้วเก็บอิสระอีกสามช่วง

```bash
python car/record.py --port COM5 --pins 35,34,32,33 --name free --sections 3 --start 1 --minutes 3
```

เดินไปมา เปลี่ยนท่าเอง ไม่ต้องตามตัวบอกท่า — ไว้ทดสอบว่าโมเดลรับมือของจริงได้ไหม

## ตรวจก่อนอัดจริง

อัดสั้น ๆ 30 วินาทีก่อน แล้วเปิดดูว่า:
* กล้องเห็นตัวเต็มตอนยกแขนขึ้นสุด และตอนนั่งยอง (ไม่โดนตัดหัวหรือตัดขา)
* ทั้งสี่ช่องมีสัญญาณ ไม่มีช่องไหนเงียบ
