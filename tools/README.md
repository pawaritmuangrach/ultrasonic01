# เครื่องมือวัดฝั่งคอมพิวเตอร์

ทุกตัวคุยกับเฟิร์มแวร์ `esp32_array/esp32_scope/` ผ่านสายอนุกรม 921600 บอด
**ห้ามเปิด Serial Monitor ของ Arduino IDE ค้างไว้** เพราะมันจับพอร์ตไว้คนเดียว
สคริปต์จะเปิดไม่ได้ทันที

ติดตั้งครั้งแรก:

```bash
pip install -r tools/requirements.txt
```

หาว่าพอร์ตชื่ออะไร:

```bash
python -c "from serial.tools import list_ports; [print(p.device, p.description) for p in list_ports.comports()]"
```

## สคริปต์ทั้งสี่ตัว ใช้ตอนไหน

| ตัว | ยิงคลื่นไหม | ตอบคำถามว่า |
|---|---|---|
| `rx_check.py` | ไม่ | วงจรภาครับปกติดีไหม ไบแอสถูกไหม มีฮัมไหม |
| `echo_profile.py` | ยิง | เสียงสะท้อนกลับมาตอนไหนบ้าง มีกี่ก้อน |
| `echo_range.py` | ยิง | ระยะเท่าไหร่กันแน่ แม่นแค่ไหน |
| `scope_view.py` | ยิง | ขอดูรูปคลื่นจริงๆ เป็นกราฟ (ต้องมีจอ) |

### 1. `rx_check.py` — เช็ควงจรก่อน ไม่ยิงคลื่น

```bash
python tools/rx_check.py --port COM5
```

ตัวแรกที่ควรรันทุกครั้งหลังต่อวงจรเสร็จ ดูสามอย่าง

| บรรทัด | ค่าที่ดี | ถ้าผิดแปลว่า |
|---|---|---|
| ไฟตรง (ไบแอส) | ~1520-1650 mV | ต่ำหรือสูงกว่านี้มาก = VREF หรือ R ไบแอสต่อผิด |
| 50 Hz | < 10 mV | เป็นร้อย mV = กราวด์ขาด หรือ Cg ค่าผิด |
| ชนราง ล่าง/บน | 0 / 0 | ไม่ใช่ 0 = สัญญาณล้น ตัดยอดไปแล้ว |

เช็คช่องที่ 2 ก็เปลี่ยนขา:

```bash
python tools/rx_check.py --port COM5 --pin 35
```

### 2. `echo_profile.py` — ดูภาพรวมว่าเอคโค่อยู่ตรงไหน

```bash
python tools/echo_profile.py --port COM5 --expect-cm 20
```

ยิง 5 ครั้ง เฉลี่ย แล้ววาดกราฟแท่งตามระยะ ผลจะออกมาหน้าตาแบบนี้

```
 ระยะ (cm)   t (µs)        mV  โปรไฟล์
       0.0        0    112.34  ##############################################
       1.7      100     48.21  ####################
      ...
      19.8     1156     11.87  #####
```

แท่งแรกคือ**พัลส์ตรง** ที่วิ่งลัดจากหัวส่งไปหัวรับบนแผ่นเดียวกัน ไม่ใช่เอคโค่
แท่งที่โผล่ขึ้นมาอีกทีตรงระยะที่วางแผ่นสะท้อนไว้ นั่นแหละคือเอคโค่

ท้ายผลจะมี "ยอดเฉพาะที่แรงสุด 5 อันดับ" พร้อม SNR เป็น dB ให้ด้วย

### 3. `echo_range.py` — เอาตัวเลขระยะจริงๆ

```bash
python tools/echo_range.py --port COM5 --expect-cm 20
```

ตัวนี้แหละที่ให้ตัวเลข "วัดได้ 20 cm" ยิง 10 ครั้ง แต่ละครั้งได้ระยะหนึ่งค่า
แล้วรายงานค่าเฉลี่ยกับค่ากระจาย

```
  ยิงที่  1: หน่วงเวลา   1198.3 µs = ระยะ   20.55 cm
  ...
ระยะเฉลี่ย  20.41 cm
กระจาย     1.20 mm  (เวลา 0.07 µs)
```

**"กระจาย" คือตัวเลขที่สำคัญที่สุด** มันบอกว่าถ้ายิงซ้ำโดยไม่ขยับอะไรเลย
คำตอบจะเด้งไปมาเท่าไหร่ ถ้ากระจายไม่กี่ mm แต่ค่าเฉลี่ยเพี้ยนไปเป็น cm
แปลว่าไม่ใช่ปัญหาสัญญาณรบกวน แต่เป็นความคลาดเคลื่อนเชิงระบบ (เช่นแผ่นเอียง)

ถ้าวัดระยะไกลกว่า 40 cm ให้เลื่อนจุดเริ่มค้นหาขึ้นด้วย ไม่งั้นมันอาจไปเจอ
หางของพัลส์ตรง:

```bash
python tools/echo_range.py --port COM5 --shots 20 --min-cm 40 --expect-cm 53
```

### 4. `scope_view.py` — ดูรูปคลื่นเป็นกราฟ

```bash
python tools/scope_view.py --port COM5
```

เปิดหน้าต่าง matplotlib สามแผง: รูปคลื่นดิบ / เอนเวโลป / FFT
ถ้าไม่มี ESP32 อยู่ตรงหน้าก็ลองของปลอมได้:

```bash
python tools/scope_view.py --simulate --distance-cm 30
```

## คำสั่งที่ส่งให้เฟิร์มแวร์ตรงๆ ได้

```bash
python tools/esp32_cmd.py --port COM5 i
```

| คำสั่ง | ทำอะไร |
|---|---|
| `i` | พิมพ์ค่าตั้งทั้งหมดที่ใช้อยู่ |
| `?` | รายการคำสั่ง |
| `r` | ยิงเบิร์สต์แล้วส่งข้อมูลกลับ |
| `q` | เก็บข้อมูลเงียบๆ ไม่ยิง |
| `f 500000` | ตั้งอัตราสุ่มเป็น 500 kS/s |
| `n 24000` | ตั้งจำนวนแซมเปิล |
| `b 8` | ตั้งความยาวเบิร์สต์เป็น 8 รอบ |
| `c 34` | เลือกขา ADC |
| `d 40000` | ปล่อยโทน 40 kHz ออก DAC (GPIO26) ไว้ทดสอบเกน |

## หมายเหตุเรื่อง t = 0

ทั้ง `echo_profile.py` และ `echo_range.py` **ไม่ได้นับเวลาจากตอนสั่งยิง**
แต่นับจากพัลส์ตรงที่อยู่ในข้อมูลเอง

เพราะ ADC ทำงานแบบวิ่งอิสระ (DMA) เฟรมที่ได้จึงเริ่มที่ไหนก็ได้ภายในหนึ่งบล็อก
256 แซมเปิล = คลาดได้ถึง ~256 µs = **4.4 cm** ถ้าใช้เวลาที่สั่งยิงเป็น t=0
ระยะจะเพี้ยนขนาดนั้นทุกครั้งแบบสุ่ม

และเหตุผลที่จัด **ยอดกับยอด** ไม่ใช่ขอบกับยอด: ทั้งพัลส์ตรงและเอคโค่ผ่าน
ทรานสดิวเซอร์ตัวเดียวกัน เวลาไต่ขึ้นราว 230-240 µs จึงเท่ากันทั้งคู่และหักล้าง
กันหมดในผลต่าง ถ้าจับขอบเทียบยอด ระยะจะเกินไปประมาณ 4 cm ทุกครั้ง
