# แผงทดลอง 150×150 มม. — RX 4 + TX 1 (สเปกสำหรับพิมพ์ 3D)

แผงเล็กสำหรับ**ลองของจริงก่อน** โดยไม่ต้องรอบัดกรีครบ 12 ช่องของแผงเต็ม
โมเดลสร้างจากโค้ด: [`plate_mini_model.py`](plate_mini_model.py) → รัน
`python hardware/plate_mini_model.py` จะได้ STEP + STL + ภาพตัวอย่างใน `cad/`
และเขียน [`plate_mini_coords.csv`](plate_mini_coords.csv) ใหม่จากตัวเลขชุดเดียวกัน

ไฟล์ที่เอาไปพิมพ์: **`cad/plate_mini.stl`**

---

## 1. ทำไมมีแผงนี้ ทั้งที่มีแผงเต็มอยู่แล้ว

แผงเต็ม (3 TX + 9 RX) ต้องบัดกรี 12 ช่องก่อนจะได้ลองอะไรเลย ตอนนี้วงจรบนแผ่นไข่ปลา
รองรับได้ **RX 4 ช่อง + TX 1 ตัว** พอดี แผงนี้จึงใช้ของที่มีอยู่แล้วได้ทันที

| | แผงเต็ม | **แผงนี้** |
|---|---|---|
| เซ็นเซอร์ | 3 TX + 9 RX | **1 TX + 4 RX** |
| ขนาดประกอบ | 298 × 262 มม. | **150 × 150 มม.** |
| ชิ้นที่ต้องพิมพ์ | ดุม 1 + แขน 3 | **ชิ้นเดียว** |
| เนื้อพลาสติก | 57.5 cm³ | 86.9 cm³ (~55 g PETG ที่อินฟิล 25%) |

> แผงนี้ใช้เนื้อ **มากกว่า** แผงเต็ม เพราะเป็นแผ่นตันทั้งผืน ส่วนแผงเต็มเป็นดุม+แขนซึ่ง
> ตัดเนื้อว่างทิ้งไปเยอะ ถ้าอยากประหยัด ลด `T` จาก 4.0 เหลือ 3.0 มม. ได้ (เสียความแข็งไปบ้าง)

## 2. พิกัดทุกตำแหน่ง (มม. จุดกำเนิด = กึ่งกลางแผง)

| id | x | y | GPIO | หน้าที่ |
|---|---|---|---|---|
| RX_TL | −55.0 | +55.0 | **IO34** | ตัวรับ ซ้ายบน |
| RX_BL | −55.0 | −55.0 | **IO33** | ตัวรับ ซ้ายล่าง |
| RX_BR | +55.0 | −55.0 | **IO32** | ตัวรับ ขวาล่าง |
| RX_TR | +55.0 | +55.0 | **IO35** | ตัวรับ ขวาบน |
| TX1 | 0.0 | 0.0 | **IO18** | ตัวส่ง |
| M0 / M90 / M180 / M270 | ±62 / 0 | 0 / ±62 | — | รูยึด ⌀4.5 + จุดอ้างอิงกล้อง |

**เบสไลน์ RX = 110 มม. ทั้งแนวนอนและแนวตั้ง**

### ทำไมจับคู่ GPIO แบบนี้

กฎที่เทรนไว้แล้วใน `car/rules.py` ใช้

```
log4 = ln( (a34 + a33 + 1) / (a32 + a35 + 1) )
```

ซึ่งคือ **ผลรวมฝั่งซ้าย เทียบ ผลรวมฝั่งขวา** ตราบใดที่ (34, 33) อยู่ซ้ายและ (32, 35)
อยู่ขวา สูตรเดิมใช้ต่อได้ทันที ไม่ต้องแก้โค้ด — ฟิตใหม่แค่ค่าความชันกับจุดตัด 2 ตัว
เพราะเบสไลน์เปลี่ยนจากของเดิม

### ของแถมที่อาเรย์เส้นตรงเดิมทำไม่ได้

วาง RX เป็นสี่เหลี่ยมทำให้ได้ **ทิศแนวตั้ง** มาฟรี ๆ:

```
log4_v = ln( (a34 + a35 + 1) / (a33 + a32 + 1) )      บน เทียบ ล่าง
```

บอกได้ว่าเป้าอยู่สูงหรือต่ำกว่าแนวแผง ซึ่งอาเรย์เส้นตรงบอกไม่ได้เลย
สำหรับรถ นี่คือความต่างระหว่าง "มีอะไรอยู่ข้างหน้า" กับ "พื้นลาดขึ้น / มีอะไรห้อยอยู่"

## 3. รูเซ็นเซอร์ — โตขึ้น 1 มม. จากแบบเดิม

| รายการ | แบบเดิม | **แผงนี้** |
|---|---|---|
| เส้นผ่านศูนย์กลางรู | ⌀19.5 มม. | **⌀20.5 มม.** |
| ตัวเซ็นเซอร์ TCT40-16 | ⌀16.0 มม. | ⌀16.0 มม. |
| ช่องว่างรอบตัว | 1.75 มม. | **2.25 มม.** |
| บอสรอบรู | ⌀23 สูง 10 | **⌀24 สูง 10** (ผนัง 1.75 มม. เท่าเดิม) |

**ทำไมโตขึ้นแล้วดีกว่า ไม่ใช่แค่ใส่ง่ายขึ้น**: โอริงที่ถูกอัดจนแบนจะนำเสียงได้มากขึ้น
ซึ่งผิดวัตถุประสงค์ของมัน (มันมีไว้ *กั้น* เสียงไม่ให้ลัดผ่านเนื้อพลาสติก) การให้โอริง
บีบพอประมาณจึงแยกเสียงได้ดีกว่าการอัดแน่น

ยังใช้โอริงเบอร์เดิมได้: **ID 15 หน้าตัด 2.0 มม. 2 วงต่อเซ็นเซอร์** (วงบน + วงล่าง
ทำให้เซ็นเซอร์ตั้งฉากและเข้าศูนย์เอง)

> **ห้ามทากาว ห้ามกดอัดจนแน่น** — จุดสัมผัสแข็งจุดเดียวก็ทำลายการแยกเสียงทั้งหมด

## 4. ร่องตัดเสียง

ร่อง **กว้าง 3 มม. ยาว 30 มม.** 4 ร่อง วางขวางแนว TX→RX ที่มุม 45° / 135° / 225° / 315°
รัศมี 33 มม. เว้นสะพานไว้ที่ 0° / 90° / 180° / 270° ซึ่งไม่มี RX อยู่

**ทุกเส้นทาง TX→RX จึงโดนร่องคั่นหมด** ต่างจากแผงเต็มที่ร่องช่วยได้เฉพาะตัวรับไกล

ระยะ TX→RX = 55√2 = **77.8 มม.** เทียบเวลาเดินทาง:

```
ผ่านเนื้อพลาสติก  77.8 mm / 2200 m/s =  35 µs
ผ่านอากาศ         77.8 mm /  343 m/s = 227 µs
```

ทั้งคู่ยังอยู่ในช่วง blanking `T0 = 1220 µs` จึงไม่โผล่มาเป็นเป้าปลอม แต่ร่องยังจำเป็น
เพราะพลังงานที่ลัดผ่านเนื้อแผงทำให้ภาครับ **อิ่มตัวและกริ่งยาว** ซึ่งกินเข้ามาในช่วงที่
เอคโค่จริงกำลังจะมาถึง

## 5. รายละเอียดอื่น

- **รูเคเบิลไทร์ ⌀3.5 คู่ละ 2 รู** อยู่ด้านในของทุกบอส (ห่างขอบบอส 8 มม.) รัดสายไม่ให้
  ดึงตัวเซ็นเซอร์ — สายที่ถูกดึงคือจุดสัมผัสแข็งที่ทำลายการแยกเสียงพอ ๆ กับกาว
- **ตัวอักษรจม 0.6 มม.** บอกชื่อรูและ GPIO ทุกจุด (`TL / IO34` เป็นต้น) ตรวจแล้วว่าไม่
  ทับรู บอส ร่อง หรือขอบแผ่น
- **`+Y` จมไว้ที่ขอบบน** กันประกอบกลับด้าน
- **รูยึด ⌀4.5 สี่รูกลางด้าน** ที่ r=62 ยึดขาตั้ง/ตัวรถได้ และใช้เป็นจุดอ้างอิงกล้องได้
  (4 จุดพอทำ homography พอดี)
- **มุมแผ่นลบ R12** กันมุมแหลมงอหลุดตอนพิมพ์

## 6. ค่าพิมพ์ที่แนะนำ

| | ค่า | เหตุผล |
|---|---|---|
| วัสดุ | **PETG** (PLA ก็ได้) | หน่วงการสั่นดีกว่า ไม่เปราะเท่า PLA |
| ความสูงชั้น | 0.2 มม. | |
| ผนัง | **4 เส้น** | ผนังบอส 1.75 มม. → 4 × 0.4 = 1.6 มม. เต็มพอดี ถ้าตั้ง 3 เส้นบอสจะพรุน |
| อินฟิล | **25% gyroid** | อินฟิลสูง = แข็ง = นำเสียง · gyroid ไม่มีเส้นตรงยาวให้คลื่นวิ่ง |
| ซัพพอร์ต | **ไม่ต้อง** | บอสพิมพ์ขึ้นด้านบน ไม่มีส่วนยื่น |
| ทิศวาง | แผ่นนอนราบ **บอสหงายขึ้น** | ผิวรูเรียบที่สุด |
