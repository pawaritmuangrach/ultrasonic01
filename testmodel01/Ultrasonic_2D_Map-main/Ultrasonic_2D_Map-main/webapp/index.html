◉ Ultrasonic-as-Camera — live mapping demo

4 receivers (A140·A80 left · C80·C140 right) + T1 transmitter → rviz-style top-down map · depth camera used only as training teacher

How it works

  1. Listen. T1 fires an ultrasonic burst (~66 kHz sampling). Each of the 4 receivers records a raw echo of 871 samples — that's the model's only input.
    inputus_XXXXXX.npz → counts[4][871]
  2. Hear shape, not noise. The echo is baseline-corrected and turned into a Hilbert envelope, then resampled to 128 range bins (bin i ≈ distance i·200/128 cm). Physics does half the work: the time axis is distance.
  3. Predict. A small 1D-CNN encoder reads the four range profiles (+ ToF & amplitude hints) and decodes a 64×48 top-down grid: 3 m wide × 2.4 m deep, each cell ≈ 5 cm, colored by obstacle distance in cm.
  4. How it learned. During training only, a depth camera provided ground-truth maps (back-projected to the same grid). The CNN was trained to imitate them from ultrasound alone — sensor distillation. At runtime no camera is needed.
  5. Accuracy. Held-out walk test: mean error ≈ 1.8 cm per cell vs 129 cm for naive ToF ray-painting.

How you feed it

  • Pick any recorded frame from the dropdown on the right, or
  • drop / browse your own us_XXXXXX.npz file (format: counts[4][871] uint16, channel order A140, A80, C80, C140).
